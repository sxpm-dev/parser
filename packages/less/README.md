# less

Less structural syntax extends the CSS schema with variables, interpolation, mixin calls, detached rulesets, and line comments.

Output is defined by schema examples. Selectors, values and expressions remain text; this package does not evaluate variables, expand mixins, or flatten nested selectors. It is a structural parser, not a complete standards validator or stylesheet compiler.

See [syntax coverage and limitations](../../docs/example-first-structure-dsl.md#css-less-scss-scope).
